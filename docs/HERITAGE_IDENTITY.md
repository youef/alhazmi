# Diwan heritage identity

The public portal and Neon member/admin pages share espresso #30251c, copper #a55339, antique gold #bd925b and parchment #f5f1eb.

Assets in `apps/web/public/brand/`:
- `heritage-hero.webp`: original generated Arabian horse and falcon desert photograph, used for home, interior and member/admin banners.
- `diwan-emblem.webp`: original transparent horse/falcon emblem, used beside accessible HTML brand text.
- `portal-heritage.css`: shared member/admin presentation, served by GitHub Pages. Existing inline styles provide a fallback.

Images generated using the built-in image generation tool. Prompts: premium cinematic Arabian horse and perched peregrine falcon in northern Arabian desert at golden dusk, dark right-hand negative space, copper/gold/brown palette, no text; transparent antique-gold Arabian horse head and falcon wing circular emblem, no letters or crown.

Publish Pages before deploying the member function so assets are available. No database or permission changes. Check Arabic and English, narrow screens, keyboard focus and existing dark-mode preference. Generated imagery is decorative artwork, not a documentary historical photograph or an officially registered tribal seal.
