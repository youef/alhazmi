# مراجعة عرض المستودع كدليل احترافي

**الهدف:** `https://github.com/youef/alhazmi` — فرع `main` عند الالتزام `54c80b8`، تاريخ المراجعة 16 نوفمبر 2026.
**الجمهور:** مساهمون ومراجعون تقنيون وأعضاء القبيلة المهتمون بالمشروع.
**المفحوص:** نسخة محلية من المستودع (شجرة الملفات، README، package.json، سير العمل، المستندات). **غير مفحوص:** الموقع المنشور وصفحة Actions ونتائجها وقاعدة بيانات Neon (لا وصول إليها من بيئة العمل).

## التقييم
مشروع جاد ومنظّم: واجهة Next.js ثنائية اللغة، خدمات Neon، ترحيلات واختبارات SQL، ووثائق معمارية وأمنية. أبرز نقاط القوة أن README يفصل بين «معتمد للنشر» و«إثبات رسمي» ويقول صراحة ما لم يكتمل. نقاط الضعف في العرض لا في الجوهر: غياب ترخيص، وملفات بناء مشفّرة داخل المستودع، وأرقام بيانات قد تتقادم.

## الأولويات
1. **لا يوجد ترخيص** — *مثبت:* لا ملف `LICENSE` في شجرة الملفات. بدونه لا يستطيع أحد قانونيًا إعادة استخدام الشيفرة. *المطلوب:* قرار من المالك (MIT للشيفرة؟ وحقوق نشر منفصلة للمحتوى التاريخي والصور؟) ثم إضافة الملف. **لم أضف ترخيصًا لأنه قرار قانوني يخص المالك.**
2. **أرقام البيانات في README** — *مُبلَّغ عنه:* «416 وحدة، 415 معتمدة»، بينما تقرير 15 نوفمبر في `docs/PRODUCTION_AUDIT_20261115.md` يذكر 415 قيد المراجعة وصفرًا معتمدًا. لم أتحقق من قاعدة البيانات. *المطلوب:* ربط كل رقم بتاريخ واستعلام أو نص مصدر، أو توليد الرقم من نقطة API عامة.
3. **حزم النشر المشفّرة** — *مثبت:* `.neon-deploy/*.zip.b64` ملفات ثنائية مُرمّزة داخل git (بحجم يفوق شيفرة المصدر)، وتاريخ الالتزامات يحوي التزامات «build: stage Neon function bundles» متكررة. *المطلوب:* إنتاجها في CI كمخرجات (artifacts) بدل تتبعها، أو توضيح سبب بقائها في README.
4. **لقطات وشرح للزائر** — *مثبت:* README نصي بلا صور. *المطلوب:* لقطتان (الرئيسية وشجرة النسب بالعربية) بعد التأكد من خلوها من بيانات أحياء أو قاصرين.
5. **ملفات المشاركة والأمان على الجذر** — *مثبت:* `docs/SECURITY.md` موجود، لا `CONTRIBUTING.md` على الجذر. *المطلوب:* ملف قصير يوضح أن البيانات لا تُقبل عبر Pull Request وأن الطلبات تمر بسير المراجعة.

## نُفِّذ في هذه الدفعة
`package-lock.json` (بناء قابل للتكرار) و`npm ci` في سير العمل، `dependabot.yml`، `sitemap` وبيانات SEO، إصلاح الروابط المطلقة للصور، وثائق التصميم.

## يستحق المشاركة
- مقتطف من `docs/ARCHITECTURE.md` يوضح فصل الواجهة العامة عن بوابة الأعضاء — *المتطلب:* لا يحوي عناوين Neon الداخلية.
- وصف قصير لسير الاعتماد من طلب إلى نشر — *المتطلب:* لا أمثلة بأسماء حقيقية.

## الحدود
