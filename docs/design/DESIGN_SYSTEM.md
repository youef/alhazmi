## 2. الرموز (Tokens) المعتمدة

تُسمّى القيم الموجودة فعليًا، ويُنقل إليها الباقي تدريجيًا. القيم من الملف الحالي.

### الألوان
| الرمز | القيمة | الاستخدام |
| --- | --- | --- |
| `--accent` | `#00633d` (ليلي `#92dfaf`) | روابط، أيقونات، حالة نشطة |
| `--text` | `#192b24` | النص الأساسي |
| `--muted` | `#725d4c` (ليلي `#b6c9bd`) | نص ثانوي |
| `--canvas` / `--surface` | `#f4f7f5` / `#fff` | خلفية الصفحة / البطاقة |
| `--soft` | `#eaf5ee` | خلفية أيقونات وشارات |
| `--line` | `#dbe5de` | حدود |
| `--gold` | `#dbbd76` | زخرفة وإبراز |
| ترابي (هوية التراث) | `#c59a67`، `#a55339`، `#30251c` | حد البطاقات، عناصر التحكم، ختم الشعار — **يُنقل إلى رموز `--heritage-*`** |

### الطباعة
خط `Noto Sans Arabic Variable` للعربية و`Figtree Variable` للإنجليزية. العناوين: `clamp(1.8rem, 5vw, 3rem)` للصفحات الداخلية و`clamp(2.7rem, 5vw, 4.7rem)` لبانر الرئيسية. ارتفاع السطر الأساسي 1.65.

### التباعد والزوايا
الحاويات `max-width: 1240px` وحشوة `clamp(18px, 4vw, 42px)`. زوايا البطاقات 16–22px (`--radius-card: 20px`). أهداف اللمس 44–48px كحد أدنى.

### نقاط التوقف
`480px` (عمودان للبطاقات) · `760px` (تذييل 3 أعمدة) · `820px` (رأس أفقي، 4 بطاقات).

## 4. الخطوة التالية المقترحة (لم تُنفَّذ)
1. نقل الألوان الترابية والخضراء إلى متغيرات في `:root` مع قيم ليلية، ثم إزالة القيم المكررة.
2. دمج طبقات `.portal-banner` في تعريف واحد وإزالة `!important`.
3. فصل `globals.css` إلى ملفات: `tokens.css`، `layout.css`، `components.css`.
4. اختبار بصري آلي (لقطات Playwright) للصفحات الخمس بالعربية والإنجليزية في الوضعين.
