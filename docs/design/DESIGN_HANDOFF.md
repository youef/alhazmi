# مواصفات التسليم للمطوّر — دفعة نوفمبر 2026

تغطي العناصر الجديدة أو المعدّلة فقط. الرموز بأسمائها من `DESIGN_SYSTEM.md`.

## 1. خطوات الاعتماد (`.approval-steps`) — الرئيسية
- **الموضع:** بعد «خدمات الديوان» وقبل شريط التراث.
- **التخطيط:** قائمة مرتبة `<ol>`؛ عمود واحد على الجوال، 3 أعمدة متساوية من 820px، فجوة 12px.
- **البطاقة:** `--surface`، حد `--line` 1px، زوايا 16px، حشوة 18px، رقم دائري 38px بخلفية `--soft` ولون `--accent`.
- **المحتوى:** عنوان قسم + 3 خطوات؛ العنوان ≤ 3 كلمات، النص ≤ ~120 حرفًا. النصوص في `i18n.ts` (`stepsTitle`, `steps`) بالعربية والإنجليزية.
- **حالات:** ثابتة (لا تفاعل). الأرقام `aria-hidden` لأن القائمة مرتبة أصلًا.
- **حالات حدّية:** نص إنجليزي أطول بنحو 25% يلتف داخل البطاقة دون ارتفاع ثابت.

## 2. التذييل (`.footer-grid`)
- **التخطيط:** عمود واحد على الجوال؛ `1.6fr 1fr 1fr` من 760px. ثلاثة أقسام: الهوية، أقسام الديوان، روابط.
- **الألوان:** خلفية `#103c2b`، نص `#e6f3eb`، عناوين `#efd1a3` (تباين ≥ 8.4).
- **الروابط:** ارتفاع أدنى 36px، التمرير يضيف تسطيرًا. «بوابة الأعضاء» و«GitHub» روابط خارجية بأيقونة.
- **الوصول:** كل `<nav>` له `aria-label`؛ عناوين `h2`.

## 3. الأصول
- استخدم `assetUrl('/brand/...')` لكل صورة في `<Image>`.
- خلفيات CSS تقرأ `var(--hero-image)` (يُعيَّن على `.site-root` من `PortalShell`). **لا تكتب عنوانًا مطلقًا.**

## 4. بيانات وصفية
- `canonical` و`hreflang` (ar/en/x-default) و`openGraph` و`twitter` من `[locale]/layout.tsx`.
- `sitemap.xml` يُولَّد من `publicPaths()` (10 صفحات).

## 5. الطباعة
`@media print` تخفي الرأس والتذييل وأدوات الدليل.

## 6. معايير القبول
`npm run typecheck && npm run lint && npm test && GITHUB_PAGES=true npm run build` تمر؛ لا ظهور لـ `youef.github.io` داخل `src/components`؛ `out/sitemap.xml` موجود.
