# المراجعة التكميلية V6 — صحة علاقات النسب والربط بين الحسابات

## المشكلات التي يعالجها الإصلاح
1. سباق المعاملات: قد تنشئ عمليتان متزامنتان علاقة دائرية دون رؤية تحديث الأخرى. أضفنا قفلًا معاملاتيًا على عمليات تعديل طبولوجيا الأشخاص والفروع والأماكن ومجموعات الأسرة، **مع اختبار حمل مطلوب قبل الإنتاج**.
2. تحديث قبيلة فرع قائم قد يترك أفرادًا أو عوائل مرتبطة بقبيلة خاطئة. تمنع قاعدة البيانات تغييره أثناء وجود مراجع حساسة؛ الانتقال الصحيح يمر بطلب تحويل موثق.
3. إعادة ربط مجموعة لديها مجموعات فرعية بأسرة ممتدة أخرى قد تؤدي لعدم الاتساق. أصبحت محظورة قبل نقل/مراجعة المجموعات الفرعية.
4. تعديل والد معتمد داخل `people` قد لا يكون له سجل إثبات مطابق. أصبحت عملية UPDATE تتطلب ادعاء نسب معتمدًا. (إدخالات INSERT التاريخية لا تزال تحتاج workflow خاصًا.)
5. التلاعب بمراجع العلاقة المعتمدة في `parentage_assertions` أصبح ممنوعًا على التعديل المباشر للأب/الأم/الابن.
6. عدم تطابق `user_profiles` و`member_login_accounts` للشخص المرتبط بالحساب أصبح محظورًا بالتحقق الثنائي.
7. منع بعض روابط عضوية مجموعات العائلة المكررة وزيادة الفهارس للمفاتيح الأجنبية والاستعلامات.

## ملاحظات وتحديات لم تحل تلقائيًا
- لا تعتبر هذه المهاجرة صلاحيات وصول تشغيلية؛ جداول التطبيق مقفلة افتراضيًا. تنفذ API وRLS لكل نوع مستخدم لاحقًا.
- `approved` لا يثبت النسب بذاته؛ يجب وجود مصادر موثوقة ومراجعات بشرية.
- يعدل كل تقرير مستقبلي عبر `graph_revision` وإبطال cache؛ لم تُنفذ منظومة الإبطال.
- لا يوجد أي اتصال قاعدة بيانات `alhazmi` حاليًا؛ لم تُختبر الترحيلات على PostgreSQL حي.
- لا تضف بيانات حقيقية أو تغيّر الأبوة/الأمومة بالاستيراد المباشر قبل تصميم معاملة اعتماد واحدة.
- القفل العام المقترح يحسن السلامة لكنه قد يقلل التزامن في التحميل الكبير؛ يحتاج قياس أو تقسيم نطاق القفل في المستقبل.
- **يجب أن يسبق V6 فحص البيانات الموجودة وإصلاح التعارضات قبل تطبيقه**؛ الفهارس الفريدة قد تُرفض إذا كانت هناك ازدواجيات سابقة.

## اختبارات لازمة عند الربط
- تغيير أب/أم دون مصدر معتمد → رفض.
- فتح حساب لنفس الشخص بهويتين مختلفتين → رفض.
- تحديث القبيلة على فرع مستخدم → رفض.
- نقل مجموعة فيها أبناء عبر شجرة أسر مختلفة → رفض.
- حقن روابط والدين متزامنة → لا دورة.
- إنشاء علاقة زواج أو سكن لا يغيّر الأبوة أو فخذ الزوجة.
- أي مستخدم غير مخول لا يشاهد هوية الآخرين.
