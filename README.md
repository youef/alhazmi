# ديوان الحازمي | Alhazmi Diwan

منصة أهلية لحفظ موروث قبيلة الحازمي وتنظيم **الأنساب والمصادر والخدمات الأسرية**، وليست جهة حكومية أو سجلًا رسميًا للأحوال المدنية.

## الروابط المنشورة

- [البوابة العامة (GitHub Pages)](https://youef.github.io/alhazmi/) — العربية والإنجليزية، دليل الأفخاذ والعوائل، شجرة وحدات النسب المعتمدة، التاريخ والأرشيف.
- [بوابة الأعضاء والإدارة (Neon Functions)](https://br-flat-boat-azy2ouq3-diwanmembers.compute.c-3.ap-southeast-1.aws.neon.tech/) — دخول الأعضاء، الخدمات، الطلبات، صلاحيات الإدارة وشجرة الأسرة المسموح بها.
- [GitHub Actions](https://github.com/youef/alhazmi/actions) — بناء واختبار الواجهة والخدمات والتحقق من النشر.

> آخر جرد للبيانات في **16 نوفمبر 2026**: 416 وحدة نسب؛ 415 تحمل حالة `approved` لنشرها بالدليل العام، وواحدة قيد المراجعة. توجد 8 سجلات أشخاص قيد المراجعة؛ **لا تُنشر بياناتهم الشخصية للعامة**. حالة الاعتماد في الديوان لا تعني إثبات نسب رسمي.

## الهيكلة التقنية

| المسار | الوظيفة |
| --- | --- |
| `apps/web` | Next.js + TypeScript + RTL/LTR، واجهة عامة ثابتة تُنشر على GitHub Pages |
| `backend/neon/api.js` | واجهة القراءة العامة المعتمدة وواجهات بيانات العضوية المحمية |
| `backend/neon/members.js` | بوابة الأعضاء والجلسات والمسارات الإدارية |
| `backend/neon/family-*.js` | طلبات روابط الأسرة ومراجعتها والتحقق والتصورات |
| `backend/neon/admin*.js` | لوحة الإدارة والعضويات والتفويضات والتدقيق |
| `backend/neon/uploads.js` | التعامل مع المستندات داخل مساحة ملفات خاصة |
| `neon/migrations` | ترحيلات PostgreSQL الخاصة بالمنصة |
| `tests` | فحوص SQL للصلاحيات وسلامة علاقات النسب |

**الاستضافة:** GitHub Pages للواجهة العامة، Neon PostgreSQL وNeon Auth وقواعد صلاحيات الخادم لبيانات الأعضاء، وNeon Functions للخدمات. فصل الواجهة العامة عن بوابة الأعضاء مقصود لحماية البيانات.

## شجرة الأنساب العامة

- تقرأ الواجهة `GET /v1/public/lineage`، الذي يعرض **الوحدات المعتمدة للنشر فقط** ولا يعيد الأفراد أو الوثائق.
- صفحة `/ar/lineage` (أو `/en/lineage`) تجلب صفحات الوحدات تباعًا لعرض الشجرة كاملة عند توافرها، مع حالة تقدم التحميل وأزرار توسيع/طي جميع الفروع.
- تحميل الشجرة محدود إلى 25 صفحة × 50 سجلًا كحد احترازي؛ إذا تجاوز عدد السجلات ذلك يظهر زر متابعة التحميل. البحث العام يستخدم الترقيم على الخادم.
- دلالات الأب/الأم/الزواج/الرعاية مستقلة في قاعدة البيانات؛ لا يُستنتج نسب من زواج أو من قرابة مدّعاة دون مراجعة.

## تشغيل المشروع واختباره

يتطلب Node.js 20.9+.

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npm run functions:check
npm run functions:test
```

يمكن مراجعة إعدادات `apps/web/next.config.ts` وملف `.github/workflows/pages.yml` للتصدير الثابت والنشر. لا تحتاج صفحات النسب العامة إلى مفاتيح قاعدة بيانات في المتصفح.

## الخصوصية وسير الاعتماد

- يمنع نشر الأفراد الأحياء والقاصرين والمعلومات الخاصة والوثائق من دون التفويض والخصوصية المناسبة.
- الطلبات الجديدة تمر بمراجعة قبل تثبيت روابط الأبوة أو المصاهرة؛ لا تتحول الأسماء المدخلة إلى حقائق منشورة تلقائيًا.
- الإدارة تقيدها الصلاحيات والنطاقات؛ صلاحية الإدارة العامة لا تعني نشر وثيقة خاصة للعامة.
- لا تضع كلمات مرور أو مفاتيح Neon أو بيانات هويات في المستودع. انظر `docs/SECURITY.md`.
- عند إجراء ترحيلات جديدة، اختبر أولًا على فرع Neon منفصل؛ لا تحذف بيانات الإنتاج.
